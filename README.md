# Xiaomi SDM845 LineageOS 22.2 Kernel
***
### Looking for a new kernel that’s built in a more timely manner? Take a look at this.
If you are interested in more timely nightly builds, you might want to check out this project:[sdm845-origin-builder](https://github.com/1992Ade/sdm845-origin-builder) by 1992Ade.  
A few days ago, I saw a post on the XDA forums. [Xiaomi SDM845 Kernels with OriginSU](https://xdaforums.com/t/originsu-susfs-kernel-for-lineageos-e-os-automated-weekly-builds.4808692/)  
1992Ade has created a GitHub Action workflow that automatically builds kernels. I think it’s a great project—if you can’t wait for a new kernel, give this a try.  
I will personally continue to maintain the BakaSU kernel in this repository.
***
